Methodology

Each exam item is classified by macroeconomic topic. When a single item involves n topics, its weight is divided equally across them, so each topic receives 1/n of an equivalent item. This preserves the total weight of each exam while allowing mixed-topic questions to be represented in the database.

The underlying workbook also contains the item-level base, validation checks, topic definitions, and the original Excel dashboard. This webpage reproduces the main dashboard and matrix in a format that works directly on GitHub Pages.
